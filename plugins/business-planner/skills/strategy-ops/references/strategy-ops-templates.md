# Strategy-Ops Templates — reference

Fill tight and numeric. Every financial figure: three-scenario range + its 2–3 driving assumptions. Re-verify external figures by web-search before locking.

---

## 1. Strategy Doc (1–2 pages max)

**Business:** · **Date:** · **Version:** · **Ambition profile:**

### Diagnosis
The 1–2 critical factors that define this situation. What is *actually* going on — the real constraint, the real opening. (Not goals. Not a SWOT dump.)

### Guiding policy
The approach that turns the diagnosis into advantage, in 2–4 sentences.
**We will NOT:** [from non-goals + hard DON'Ts — binding]

### Coherent actions (3–7, sequenced, mutually reinforcing)
| # | Action | Why it reinforces the policy | Sequence rationale (incl. competition heat-map) |
|---|---|---|---|

### Moat trajectory
What compounds with time/scale here (Seven Powers lens) — or the honest "nothing yet; edge is speed + service until X."

### Scenario table
| Scenario | Leading indicators (earliest tells) | Pre-committed response | Cash effect |
|---|---|---|---|
| Base | | Run the plan | |
| Squeeze (costs +20%, sales −30%, payments late) | | | |
| Breakout (demand > plan) | | | |
| Kill ([core assumption] fails) | | Stop/pivot per kill number | |

### Tripwires (specific · measurable · dated · reviewed monthly)
| # | Tripwire / tell | Threshold | Check cadence | Pre-committed action |
|---|---|---|---|---|
*(Include competition-sim tells as monitors.)*

### 18-months-plus (one paragraph only)
Directional bets, revisited quarterly. No detail — detail here is fiction.

## 3. Investment Card (one per idea — makes ideas comparable)

**Idea:** · **Date:** · **Ambition profile:** · **Founder discount rate used:** [their REAL cost of capital: gold-loan/FD-alternative for MSME, opportunity-cost salary, or venture hurdle — state it, never a textbook 10%]

| Metric | Bear | Base | Bull | Driving assumptions (2–3) |
|---|---|---|---|---|
| Money in, staged (₹) | | | | tranches + what unlocks each |
| Founder time in (hrs/wk × months, priced @ ₹__/hr alt-wage) | | | | |
| Payback (months) | | | | |
| **NPV** @ __% (₹) | | | | price · volume · margin |
| **IRR** (%) | | | | |
| Owner earnings Y1 (₹) | | | | |
| Owner earnings Y3 (₹) | | | | |
| Max drawdown (worst cash hole, ₹ + month) | | | | working-capital cycle |
| Reversibility (% recoverable if killed at month 6) | | | | asset resale · lease exit · inventory |

**The call:** GO / NO-GO / PIVOT / PILOT — one line of reasoning.
**Riskiest assumption still open:** · **Next dated test:** · **Kill number:**

*Comparing ideas: put two cards side by side; compare NPV/IRR at the SAME discount rate, then payback, drawdown, reversibility, and founder-fit. The best idea on paper loses to a worse idea the founder can actually execute — check the Founder-Fit Map before deciding.*

**Honesty note:** a pre-revenue NPV/IRR is a structured guess, not a valuation. Its value is (a) forcing the assumptions into the open and (b) comparability across ideas. Present ranges, never one confident number.
